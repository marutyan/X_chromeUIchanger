# Manual Smoke Test

実行していない項目をPASSに変更しないこと。
検証実施時の環境（Commit SHA, Chromeバージョン等）を必ず記録する。

## Environment

- Commit SHA: 要記入
- Chrome version: 要記入
- OS: 要記入
- Display resolution: 要記入

## Installation & Setup

1. `npm install`
2. `npm run build`
3. Chromeのアドレスバーに `chrome://extensions/` を入力して開く
4. 右上の「デベロッパー モード」を有効化する
5. 「パッケージ化されていない拡張機能を読み込む」をクリックし、本リポジトリの `dist/` ディレクトリを選択する
6. ソースコード更新時は `npm run build` を再実行後、拡張機能管理画面の更新ボタンおよびXのタブをリロードする

## Checklist

| 項目 | テスト内容 | 結果 | 観測結果 |
|---|---|---|---|
| 1. ホームタイムライン | ホーム（`x.com/home`）でタイムライン幅が自然に拡大（最大900px）し、可読性が維持されるか | NOT RUN | |
| 2. 左ナビゲーション | 左側のメニュー（ホーム、通知、メッセージ等）の配置・幅・クリック操作が標準のまま正常動作するか | NOT RUN | |
| 3. 右サイドバー | 右側の検索窓、トレンド、おすすめアカウント等の幅が350pxで固定され、レイアウト崩れがないか | NOT RUN | |
| 4. 単一画像ツイート | 写真が1枚添付されたツイートの画像幅がカラム幅に合わせて自然に広がるか | NOT RUN | |
| 5. 複数画像グリッド | 写真が2〜4枚添付されたツイートのグリッドレイアウトが崩れずに幅追従するか | NOT RUN | |
| 6. 動画ツイート | 動画・GIFプレイヤーの幅がタイムライン幅に追従し、再生・停止・全画面表示が正常に動作するか | NOT RUN | |
| 7. リンクカード (OGP) | Webサイトリンクのサマリーカード（card.wrapper）が横幅いっぱいに自然に広がるか | NOT RUN | |
| 8. 引用ツイート | 引用ツイートの枠線・内包ツイートが横幅いっぱいに収まり、はみ出しがないか | NOT RUN | |
| 9. ポスト詳細表示 | 任意のツイートをクリックして `/status/...` 画面に遷移した際、メインツイートと返信一覧がワイド表示されるか | NOT RUN | |
| 10. 長文記事 (Articles/note) | 長文ポストやX Articlesを開いた際、記事ブロックがタイムライン幅に沿って適切に拡大表示されるか | NOT RUN | |
| 11. ウィンドウリサイズ拡大 | ブラウザウィンドウを横に広げた際、タイムライン幅が最大900pxまで滑らかに追従するか | NOT RUN | |
| 12. ウィンドウ縮小 (Compact) | ブラウザウィンドウを幅990px未満に縮めた際、自動的にCompactモードとなりX標準表示に戻るか | NOT RUN | |
| 13. Chrome ズーム変更 | ズーム倍率を 80%、100%、125% に切り替えた際、左右カラムの重なりやレイアウト崩れが発生しないか | NOT RUN | |
| 14. SPA画面遷移 | ホーム ⇄ 通知 ⇄ メッセージ ⇄ プロフィール ⇄ 検索結果 へページリロードなしで遷移した際、レイアウトが追従するか | NOT RUN | |
| 15. ポップアップ OFF 切り替え | 拡張機能アイコンをクリックして「Layout」トグルをOFFにした際、即座にX標準の狭い幅へ復帰するか | NOT RUN | |
| 16. ポップアップ ON 切り替え | トグルをONに戻した際、即座にワイドレイアウトが再適用されるか | NOT RUN | |
| 17. 横スクロールなし | ページ全体（body/html）に不要な横スクロールバーが出現していないか | NOT RUN | |
| 18. ダイアログ・モーダル | 画像拡大表示モーダルやポスト投稿ダイアログを開いた際、表示が歪んだり操作不能にならないか | NOT RUN | |

## Failure capture

テスト結果が FAIL となった場合は、以下の情報を記録すること:

1. 発生画面のURL種別（ホーム、ポスト詳細、検索結果など。アカウントIDや非公開情報は伏せる）
2. ウィンドウ実測幅、ズーム倍率、ディスプレイ解像度
3. 崩れた要素名および症状
4. DevToolsで確認した該当要素のセレクタ・属性（`data-testid`, `role`, クラス名）
5. 不具合の再現手順
6. スクリーンショット（個人情報・機密情報が含まれないよう注意）
